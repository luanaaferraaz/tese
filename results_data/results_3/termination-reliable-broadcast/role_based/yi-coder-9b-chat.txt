1. Termination – satisfied
The protocol ensures that every correct process eventually delivers a message by ensuring that each round has at least one correct process and there is always a decision made in the end of each round. The rounds are numbered from 1 to f+1, where f is the maximum faulty processes allowed. For every round r≤f+1, if no new process fails, it ensures that any message m is delivered by the end of the protocol execution since all correct processes have received and relayed this message in previous rounds.

2. Validity – satisfied
If s is a designated sender and broadcasts m, then all correct processes eventually deliver m because every round r≤f+1, the sender sends the message to all processes, and by I1 each process has it by the end of round f+1.

3. Agreement – satisfied
If a correct process delivers m, then all correct processes eventually deliver m as explained in Validity property.

4. Integrity – satisfied
Every correct process delivers at most one message because every process maintains two flags: delivered and received_msgs which ensures that each process sends the same message to all processes throughout rounds, and only once it delivers a message. The integrity is preserved by ensuring that every delivered message must have been broadcasted by s. If m was delivered, it must have been part of the received_msgs set. Therefore, if m was not SF, then s must have sent it in some round which is guaranteed based on I1 and I2.

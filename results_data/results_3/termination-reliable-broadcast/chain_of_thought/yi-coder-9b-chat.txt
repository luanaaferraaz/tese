1) Termination: Every correct process eventually delivers some message. This is guaranteed by the end of round f+1, which happens after n rounds (when a new value m can be delivered) or (f+2) rounds (when SF can be delivered if no value has been delivered yet) assuming n>f and the sender s is always correct.

2) Validity: If s is correct and broadcasts m, then all correct processes eventually deliver m. This is guaranteed by the fact that every round broadcasts the same message, so if a correct process receives it in some round r≤f+1, it can be delivered at the end of that round. Afterwards, all other correct processes must have received it as well.

3) Agreement: If a correct process delivers m, then all correct processes eventually deliver m. This is guaranteed by the fact that every round broadcasts the same message and that a value or SF is delivered strictly at the end of the f+1th round, after all other rounds are finished.

4) Integrity: Every correct process delivers at most one message. If it delivers m=/SF, then m was broadcast by s. This property follows from the fact that each process only broadcasts a value once (in Round 1) and can only deliver one message at the end of round f+1. It is also guaranteed by the fact that if a process has delivered a message m, it will not deliver another until the next round starts where s broadcasts again.

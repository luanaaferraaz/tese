Termination - [satisfied]
The protocol guarantees that every correct process eventually delivers some message. This is because the rounds are based on a fixed upper bound (f+1) and all processes are aware of the termination condition, which is when they have received a message for round f+1.

Validity - [non satisfied]: The sender’s message should be broadcast by s.
The protocol doesn't guarantee that if s is correct and broadcasts m, then all correct processes eventually deliver m. The only agreement ensured in the protocol is if a correct process delivers m, then all correct processes eventually deliver m (Integrity property).

Agreement - [satisfied]
If a correct process delivers m, then according to I1 every other correct process has m in their received_msgs set by round f+1.

Integrity - [non satisfied]: Every correct process delivers at most one message.
The protocol doesn't ensure that every correct process delivers at most one message because there can be more than one message in the received_msgs set if multiple rounds have been executed and each of them has received a different value from s.
